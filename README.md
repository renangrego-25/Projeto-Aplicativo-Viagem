- Finalizado em:
- Status: Em andamento

## 📌 Sobre o projeto

 Projeto desenvolvido com foco em estudar e aprofundar conhecimento em Javascript, IA generativa e conexões API. Visando criar um aplicativo moderno e funcional, juntamente com implementações de IA generativa para auxiliar usuário, além de estudar como é o comportamento de uma IA e como ela pode aprender dentro de um sistema fechado. IA escolhida primeiramente foi a Ollama, subistituida pelo Gemini.

## 🎯 Objetivo

- Aprofundar conhecimento em Javascript, com repetição e memorização de código
- Desenvolver aplicação com integração de uma IA via API.
- Desenvolver conhecimento de conexões API.

## ✨ Funcionalidades

- Arquivar documentos para controle em um só lugar, como passagens, hospedagem, documentos pessoais e etc.
- Lista para controlar viagem.
- Criação de um itinerário com data e local.
- Conversão de moedas para auxiliar no controle financeiro.
- IA integrada para auxiliar e tirar dúvidas de usuário como "onde passear?" "onde comer?" ou qualquer outra dúvida pertinente em relação a viagens.
